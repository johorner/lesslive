## 用 LessLive 驱动生活

LessLive帮助我们把复杂生活拆解为可理解、可设计的结构，用来构建并驱动自己的生活。

你可以结合自己的真实意愿、现实条件和实践经验，按照 LessLive 模型的结构和方法，在真实生活中对目标、策略、方案、计划等行动安排进行规划与设计，并持续更新和迭代，最终得到属于自己稳定运行的个人生活模型。

### 一、首先结构化｜让生活井井有条

**把生活解构为边界清晰且彼此关联的模块，不再混乱和无序**

```
第一课题/
├── 内驱力/        # 给生活装上方向盘和一台马力强劲的发动机
│   ├── 愿景/      # 大富大贵还是小富即安？众星捧月还是 underdog？
│   ├── 使命/      # 去改变世界拯救人类，还是为 100 个客户提供终身满意的服务？
│   └── 主张/      # 立场坚定吗？逻辑完整吗？证据充分吗？
├── 主体性/        # 能不讨好不迎合，不被外界裹挟，站着把钱就挣了。
│   ├── 思考/      # 我思故我在，未经思考的人生不值得，让思想成为生活的能源
│   ├── 画像/      # 把自己抽离出来成为自己的观察者，看到自己真实样子
│   └── 树洞/      # 非理性的自己太合理了，把内心那个脆弱的家伙放出来吧
└── 生命力/        # 兴趣和爱好是生活自洽后的奖赏而非前提，除非用它们谋生

第二课题/
├── 蓝图/          # 有内驱力在，失业、改行、换赛道，太正常了，重新设计一套方案而已
├── 旅程/          # 直接用 AARRR 五个动作作为永续目标，设计 OKR 的精力也不能浪费
├── 能力/          # 品牌故事设计、对外表达策略，第一人称法则，让内容选题和创作不再消耗精力
└── 触点/          # 把各种攻略和干货等公开知识赶出笔记库，只沉淀自己的经验和教训

第三课题/				
└── [项目名]/      # 把自己和受众从二元对立变成肩并肩的战友和同志
    ├── 产品/      # 发自内心的热爱并持续投入精力而产生的价值
    ├── 故事/      # 和受众一路走来并将持续走下去的点点滴滴
    └── 社区/      # 以“我”为圆心，画个充满烟火气和人情味的小圈圈
```

## 使用方法

1. 下载或克隆本仓库，用 Obsidian 打开，操作 LessLive 模型并沉淀为个人资产
2. 阅读 LessLive 作者本人使用 obsidian 的[插件清单与配置说明](系统服务/指南/插件说明.md)，获得更好操作体验
3. 内置预设了 AI 协作体系，接入 AI 协助自己理解并构建 lesslive 模型
4. 与目录同名的 markdown 文件是模型各组件和模块的设计和使用说明
5. 参考示范内容，开始构建自己的 lesslive 模型

声明：属性里有`tags: [example]`标签的内容，是作者本人的真实生活记录，作为使用 lesslive 模型的参考和示范，不构成任何形式的效果保证、专业建议，使用者自行承担使用的全部风险。
