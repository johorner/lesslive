## 给人类用的 Skills？
AI 通过 Skills 知道怎么做事而越来越强，人类同样可以用 Skills 把生活经营得越来越好。
Lesslive 把生活拆成与自己、与世界、与他人相处的三套技能，帮助我们构建生活系统。

| 技能分类           | 核心问题         | 主要产出              |
| :------------- | :----------- | :---------------- |
| **第一课题：和自己相处** | 如何看清自我，构建内核？ | 不迎合、不讨好、不被外界裹挟的自我 |
| **第二课题：和世界相处** | 如何落地目标、立足行动？ | 低成本、少依赖的谋生策略和外部环境 |
| **第三课题：和他人相处** | 如何建立关系、协作互动？ | 把买卖变成和一群人共同创建的生活圈 |

---
## LessLive Skills

每个模块都是一个 Skill，告诉你如何做某件事：
- 如何设计愿景和使命
- 如何管理目标和关键成果
- 如何构建个人品牌
- 如何运营社群

每个 Skills 共同构建起一套生活运行系统，实现：
- 发自内心的热爱而产生的强大内驱力，从不看他人脸色
- 没有收件箱的笔记库，很快就清空的待办，轻松惬意没有内耗
- 朋友圈都是自己关心和关心自己的人，他们甚至是自己的客户
- 从不为内容创作发愁，项目的进度就是源源不断的选题库

---
## 核心特色
### 结构化｜让生活井井有条
**把生活解构为边界清晰且彼此关联的模块，不再混乱和无序**
- 每个模块都有专属 Skill ，明确输入输出
- 严格的架构层级和依赖关系，构成可驱动真实生活的系统

### 最小化｜让自己轻装上阵
**只保留确实需要且只需要的最少必要条件，扔掉包袱和消耗**
- **品牌故事设计**：用课题分离设计边界清晰的故事，避免讨好迎合而内耗
- **对外表达策略**：展示价值、汇报进度、提供服务，源源不断的内容选题
- **第一人称法则**：从我，到我和你，再到我们一起，信手拈来的内容创作
- **AARRR-OKR**：用生命周期管理目标与关键成果，每场战役都使命必达
### 资产化｜把时间变成资产
**用作个人仓库，把实践的经验、财富和人脉沉淀为个人资产**
- 第一课题：沉淀认真思考过的内容，掌控自己的欲望、责任和边界
- 第二课题：沉淀和世界打交道的策略和方法，踩过的坑和吃过的亏
- 第三课题：沉淀与受众的互动和故事，见证社会资本的形成与累积

## 适合谁？

- ✅ **想要清晰行动指南的人**：不要模糊的理论，要可执行的 Skills
- ✅ **obsidian 用户**：使用 Obsidian 实现，体验更佳
- ✅ **独立工作者**：自由职业者、创业者、个人品牌经营者
- ✅ **信息过载者**：被笔记、待办、社交网络淹没的人
- ✅ **极简主义者**：追求 Less is More 的生活方式
- ✅ **雨燕族**：没有依靠，必须靠自己并一直飞行的独立个体

❌ **不适合**：
- 追求"完整知识体系"的第二大脑信徒
- 想要现成答案的人（LessLive 是 Skills，需要你自己执行）
- 不愿意动手实践的人
## 快速开始

### 1. 下载仓库

```bash
git clone https://github.com/johorner/lesslive.git
```

### 2. 打开仓库（支持 Markdown 的工具）
- 使用 obsidian（推荐）
- 打开 LessLive 仓库目录
- 接入本地 AI agent（可选）

### 3. 安装 Obsidian 插件（可选）
参考[插件说明](系统服务/指南/插件说明.md)，安装以下插件获得更好体验：
- **Make.md**：文件夹笔记和自定义排序
- **Dataview**：动态查询内容
- **Kanban**：看板管理

### 4. 开始使用
1. 阅读 `第一课题/第一课题.md`，了解如何和自己相处
2. 参考 `tags: [example]` 的示范内容，看作者如何使用
3. 在 AI 的协助下，开始构建你自己的 LessLive

## 作者声明

我是一个独立工作者，一只一生都在飞行的雨燕。我设计了 LessLive 来管理自己的生活和项目，帮我卸掉负重，飞得更高、更远。

✅ **LessLive 是：**
- 一套思维模型，用来梳理自我、谋生、人际；
- 一套 Markdown 文档，不限定编辑器；
- 一组创新工具，可以按需取用部分模块，不必全部采纳。

❌ **LessLive 不是：**
- 不是 Obsidian 专属模板，任意 Markdown 工具均可使用；
- 不是拿来直接复制套用的现成知识库；
- 不是一套标准答案，不会替你做人生决策；
- 不强制你去建立圈子、构建共同体。

> 💡 仓库中带 `tags: [example]` 的内容，是我的真实生活记录，供你参考。但这不构成任何效果保证或专业建议，使用风险自负。

期待你的反馈，并与你共同完善这套适合“雨燕族”的飞行系统。
