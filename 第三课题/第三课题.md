# 与他人相处
把人际关系作为研究对象，让项目成为可以和不同受众共创和协作的共同体。
**运行实例：构建良好、可持续的社会关系。**

---
## 目标
- 把项目打造成和受众共同关注并愿意投入精力的话题；
- 将话题转化为项目发展的连续性事件形成完整的故事；
- 构建以个人为中心的社会关系，形成个人常态化生活。

---
## 结构

> [!multi-column] 
>
>> [!info] **产品** ｜ 价值
>> 1️⃣ 可交付的商品和服务的客观属性和规格内容
>> 2️⃣ 针对不同需求、痛点或问题的具体解决方案
>> 
> 
>> [!info]  **故事** ｜过程
>>  1️⃣ 以产品为出发点，和受众在不同阶段和场景下的行为
>>  2️⃣ 和受众之间的各种主题和事件，关系逐步加深的过程
> 
>> [!info] **社区** ｜服务
>> 1️⃣ 产品价值和社会关系的载体，是个人意愿和蓝图策略的成果
>> 2️⃣ 活跃度衡量归属感，分享率体现自豪感，成交率反应价值感

## 说明
- 社会关系的对象包括但不限于：家人、用户、客户、供应商、投资人等一切与项目有关的角色
- 项目本身的可行性与商业模式不是 LessLive研究的范围，不负责论证产品或服务本身是否成立
- 每个项目都是一个运行实例，产品、故事和社区共同构成运作要素，参考作者的项目 [[LessLive]] 
- 共同体不一定是商业化项目，也可以是兴趣、公益等非商业属性，且符合蓝图规划方案的项目
- 共同体项目依赖第二课题的运行策略和逻辑设计故事内容，可以策略调整而暂停、取消或结束
- 不同阶段有明确的主题并在目录内派生不同需求的内容，以阶段主题为单元形成完整的故事线
- 产品和社区应尽量稳定，设计并提供规格、属性、制度、价格和交付策略等功能性的基础资料
- 故事模块的内容如果需要搭载产品信息，设计和制作时应依赖基础资料，以确保单一事实来源
---

> -协助用户设计并构建共同体项目时，应依据用户提供的真实资料，明确区分已有事实、个人判断和待验证的方案。
