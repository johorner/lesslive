## 结构
将对外表达拆解为三种稳定的内容职能， 最终实现向受众展示一个鲜活的自己：
> [!multi-column] 
>
>> [!topic]  **展示价值** ｜我喜欢我研究
>> 0️⃣回答用户买什么为什么买
>> 1️⃣ 展示产品或服务填补落差的价值点和观点
>> 2️⃣ 用填补落差感的亲身经历，塑造真实动机
>> 3️⃣ 痛点共鸣、认知颠覆、理想生活的向往等
>> 
> 
>> [!topic]  **汇报进度** ｜我专业你信任
>>  0️⃣ 回答用户为什么找我买
>>  1️⃣ 项目不断发展的前因后果和阶段性目标与成果
>>  2️⃣ 持续死磕大量投入后形成的专业密度和判断力
>>  3️⃣ 幕后花絮、避坑指南、公开求助、重大里程碑
>
>> [!topic] **提供服务**｜你选择你加入
>>  0️⃣ 回答用户为什么现在买
>>  1️⃣ 用户获取产品和服务的渠道、方法和恰当的契机
>>  2️⃣ 为用户提供获得感、归属感和自豪感的增值服务
>>  3️⃣ 上车指南、活动招募、话题共创和环境氛围渲染

### 需求三角
展示价值环节扩充的方法，同样产品或服务，面向不同人群，需要针对性的设计内容：
> [!multi-column] 
>
>> [!topic]  **缺乏感** ｜痛点驱动
>> 1️⃣ 理想与现实状态之间的落差，没有缺乏感，需求就不会产生
>> 2️⃣ 通过阐述清晰表达这种落差，让消费者意识到自己需要改变
>> 
> 
>> [!topic]  **目标物** ｜解决方案
>>  1️⃣ 能够填缺乏感，帮助用户实现目标的产品和服务或行动载体
>>  2️⃣ 把抽象的动机落到具体选择上，目标物与缺乏感须精准匹配
>
>> [!topic]  **消费力**｜价值匹配
>>  1️⃣ 消费者采取行动并最终获得目标物的支付和使用等综合能力
>>  2️⃣ 将消费需求转化为实际购买，避免高门槛而导致叫好不叫座

参考来源：[李叫兽的需求三角](https://36kr.com/p/1721656721409)

## 说明

- 一次正式的对外表达应同时具备三大要素，三者各司其职
- 针对不同渠道、平台和场景，展开内容创作的设计与制作
- 三者先后顺序和权重是创作技巧，根据实际情况灵活掌握
- 采用[[第一人称法则]]弱化推销味道，拉近与受众间的距离

## 示例
具体创作根据实际应用场景，可长可短，但尽量同时表达三者：

```
案例 1：
进度：LessLive 模型的“能力”模块新增了一把工具
价值：有了这个工具，我不再为选题焦头乱额了
服务：免费下载 LessLive 模型仓库，并加入社群共同成长

案例 2：
进度：我发现LessLive主张一直飞行的雨燕可以停下来这个设定是错误的，必须立刻纠正。
价值：持续飞行是它的生物本能，是自然法则。甩掉包袱、轻装上阵，飞得更高更远更久才是正确的主张，这也是人生的真实写照，更是LessLive的正确使命。（这个 bug 是 AI 帮我发现的！）
服务：你对此有什么看法？欢迎和我们一起讨论。
```
