## 核心定义

基于阿德勒心理学的课题分离原则，构建“我”与“你”（我和目标受众）的边界，让自己可以专注在热爱的领域，不以迎合受众或控制其反应为目标，保护自我能量、拒绝内耗的一份完整的叙事框架。
## 我的课题
沉浸在自己的热爱里，专注构建并强化自己的竞争力，拒绝讨好与迎合而产生的内耗：

> [!multi-column] 
>
>> [!topic]  **我喜欢** ｜源自热爱
>> 0️⃣ **起点**：我对什么着迷
>> 1️⃣ 发自内心的纯粹热爱与对理想状态的向往
>> 2️⃣ 暴露真实的需求与未曾填补的现实落差感
>> 3️⃣ 借由亲身体验，向世界发出的第一声呐喊
>> 
> 
>> [!topic]  **我研究** ｜持续投入
>>  0️⃣ **过程**：我探索与死磕
>>  1️⃣ 长期主义的硬核钻研与对底层规律的拆解
>>  2️⃣ 在无人问津处默默支付的时间与精力成本
>>  3️⃣ 沉淀出的方法论，以及对不确定性的对抗
>
>> [!topic] **我专业**｜形成信任
>>  0️⃣ **结果**：独特的判断力
>>  1️⃣ 经过千锤百炼、形成肌肉记忆的硬核手段
>>  2️⃣ 能够拿出手、经过精心打造的产品或服务
>>  3️⃣ 构筑起的壁垒，以及我能给出的最高承诺

## 你的课题
坚信这是自己持续投入后的必然结果，并用感恩心态提供服务以报答，形成良性循环：

> [!multi-column] 
>
>> [!topic]  **你信任** ｜建立链接
>> 0️⃣ **起点**：你开始认可我
>> 1️⃣ 被我的热爱所唤醒的、你对理想生活的向往
>> 2️⃣ 被我的经历所疗愈的、你感同身受的落差感
>> 3️⃣ 借由真诚的碰撞，在你心中种下的一颗种子
>> 
> 
>> [!topic]  **你选择** ｜实现转化
>>  0️⃣ **过程**：你决定选择我
>>  1️⃣ 顺应你自身节奏的、绝不强求的确定性入口
>>  2️⃣ 恰好解决你当前问题的刚好适配你的工具箱
>>  3️⃣ 采用我的方案为你省下了的时间和精力成本
>
>> [!topic] **你加入**｜共同成长
>>  0️⃣ **结果**：你我成为我们
>>  1️⃣ 你热情的反馈和评价，让我的热爱有了意义
>>  2️⃣ 让你获得归属感与自豪感成了我的全新动力
>>  3️⃣ 共同见证我们的故事，并持续创造精彩瞬间

## 使用说明

- 使用这套逻辑作为人际关系画像分析的分类依据，在这条逻辑线上的是一个类型
- 课题分离是一个需要长期训练和逐渐养成的能力，不要急于求成，长期自我察觉
- 可以基于这个框架，把当前正在推进的项目，写一份简单的文档，以便查漏补缺
- 逻辑通顺后，作为三大课题核心模块设计与构建的依据，产出首版可运行的模型

---
> [!ai]- AI 辅助
> 用这个模型来协助用户设计并构建自己的核心叙事框架

> 核心目的是让用户形成一套整体的叙事逻辑，为三大课题的设计与构建提供依据。
