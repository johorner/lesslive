# 与世界相处
把谋生手段作为研究对象，以精准触达为目标，结合外部资源环境和个人能力，设计高效的运行策略。
**运行环境：构建低成本、少依赖的生存与生活条件。**

---
## 目标
- 认识现实客观条件，辨明自身实力和能力，研究外部环境以及可用资源；
- 设计运行策略，将个人意愿转化为符合自身条件的行动目标和关键成果；
- 构建运行环境，选择、组装和编排相关资源，为运行实例提供可用条件。

---
## 结构

> [!multi-column] 
>
>> [!info] [[蓝图]] ｜**给方向**
>> 1️⃣ 为兑现个人愿景和使命，经过特别设计、科学推演后制定的行动策略
>> 2️⃣ 针对不同阶段或背景设计的行动方案构建适合自己的生存与生活环境
>> 
> 
>> [!info]  [[旅程]] ｜**给路径**
>>  1️⃣ 将蓝图方案解析为具有完整生命周期的目标与关键成果的可视化系统
>>  2️⃣ 识别行动所需资源，明确组织与管理要求，持续跟踪进展并反馈调整
> 
>> [!info]  [[触点]] ｜**给资源**
>> 1️⃣ 将踩过的坑、吃过的亏作为宝贵的经验沉淀为个人资产，并持续积累
>> 2️⃣ 为实现蓝图目标，提供个人经验和方法，提升成功率，避免重复犯错


> [!info]  [[能力]] ｜**给方法**
> 1️⃣ 内置官方能力库为构建和运行LessLive模型提供专属工具与方法
> 2️⃣ 沉淀实践应用中的心得和经验，并分享到社区，和大家共同成长

## 说明
- 第二课题是 LessLive 的内部运行后台，相当于作战指挥室，蓝图定战略，旅程设计战役，能力提供具体战术，而触点是经验库。
- 它基于个人内驱力、现实条件、外部资源的实践经验和 LessLive 专属方法，形成并调整运行策略与行动计划，在实践中依据反馈持续取舍和调度。
- 这里的内容主要服务个人决策与内部运行，通常不直接对外发布。需要与他人沟通或共同参与的内容，应由第三课题组织为共同体项目。
