## 定义
与目录同名的 markdown 文件是 `文件夹笔记`，它位于该目录下，通过导航器面板的目录树选择该目录后，编辑器页面会显示该文件的内容，是该目录的描述和说明。
## 应用
### 模块入口
LessLive 模型各领域、组件和模块的入口描述，帮助理解他们的使用方法。
`试着从目录树随便选择一个目录，单击打开文件比笔记`

```text
第一课题/														# 文件夹（目录）
├── 第一课题.md    									# 文件夹笔记，该领域的入口和描述
├── 内驱力/ 												# 组件一
 │				├──内驱力.md 								#文件夹笔记，该组件的入口和描述
├── 主体性/    		    									# 组件二
 │				├──主体性.md 								#文件夹笔记，该组件的入口和描述
└── 生命力/   												# 组件三
		  └── 生命力.md   							# 文件夹笔记，该组件的入口和描述
```

### 内容草稿
用内容主题创建文件夹，把文件夹笔记当做该主题内容的草稿，记录灵感和原始信息，便于后期二次加工和派生其他形式的内容，以实现以内容主题为单位的高内聚文档管理。

```text
马瑟兰的品牌故事/			# 文件夹（目录）
├── 马瑟兰的品牌故事.md    # 文件夹笔记，最原始的内容，作为派生产物的底层依赖
├── 直播间.md 			# 编写直播间的口播内容和互动方案
├── 公众号.md    		# 创作符合发布到公众号的文章
├── 视频号.md			# 创作短视频脚本和口播文案
├── 活动方案.md	    # 以该内容为主题的用户活动方案，比如发布媒体时搭配的促销方案，用户互动等
└── 朋友圈.md    		# 创作适合发布到朋友圈的图文
```
