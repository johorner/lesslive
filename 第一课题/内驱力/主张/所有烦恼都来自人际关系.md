## 立场

**我赞成：**
- 所有烦恼本质上都来自人际关系（包括与社会期待、外部评价的关系）
- 通过课题分离，可以从人际关系的烦恼中解脱
- 与他人建立横向关系，而不是纵向关系（竞争、比较、上下级）
- 我只对自己的课题负责，别人的课题归别人

**我反对：**
- 把别人的课题当成自己的课题（过度承担、讨好、迎合）
- 把自己的课题推给别人（依赖、抱怨、指责）
- 为了获得认可而扭曲自己
- 在比较和竞争中消耗生命

## 依据

### 外部理论：阿德勒《被讨厌的勇气》

**核心观点：**
> "所有烦恼都是人际关系的烦恼。"

**课题分离：**
- 明确"这是谁的课题"
- 我的课题：我的选择、我的行动、我的感受
- 别人的课题：别人如何评价我、别人是否认可我、别人是否喜欢我
- 不干涉别人的课题，也不让别人干涉自己的课题

**横向关系 vs 纵向关系：**
- 纵向关系：上下级、竞争、比较（"我比你强"、"你不如我"）
- 横向关系：平等、合作、尊重（"我们不同，但平等"）
- 烦恼来自纵向关系，自由来自横向关系

### 客观事实

**单独一个人时，不存在烦恼：**
- 没有人际关系，就没有"被评价"的焦虑
- 没有比较对象，就没有"不够好"的痛苦
- 没有社会期待，就没有"应该成为什么样"的压力

**烦恼的常见表现都与人际关系相关：**
- 焦虑：担心别人如何看我
- 自卑：和别人比较后觉得不够好
- 愤怒：别人没有按我的期待行事
- 委屈：为了获得认可而扭曲自己
- 疲惫：承担了不属于自己的课题

## 论证

### 核心推导

```
前提 1：烦恼来自"期待与现实的落差"
前提 2：人际关系中的期待包括：我对别人的期待、别人对我的期待、社会对我的期待
前提 3：这些期待无法完全控制，因为涉及别人的课题

结论：人际关系是烦恼的根源，课题分离是解脱的关键
```

### 详细论证

**1. 烦恼的本质是"期待落差"**
- 我期待别人认可我 → 别人不认可 → 烦恼
- 我期待自己比别人强 → 发现不如别人 → 烦恼
- 社会期待我成功 → 我没达到 → 烦恼

**2. 期待落差源于"课题混淆"**
- 别人是否认可我 → 别人的课题，我无法控制
- 我是否比别人强 → 把别人当成竞争对象，陷入纵向关系
- 社会如何评价我 → 社会的课题，我无法控制

**3. 课题分离带来自由**
- 我的课题：做我认为对的事
- 别人的课题：别人如何评价、是否认可
- 我只对我的课题负责 → 即使被讨厌，也是别人的课题

**4. 横向关系消除比较**
- 不和别人比较 → 没有"不如别人"的自卑
- 不追求优越感 → 没有"必须超过别人"的焦虑
- 平等对待每个人 → 没有"上下级"带来的紧张

## 支撑的内驱力

这个主张为我的生活方式提供理论支撑：

**支撑 [[希望雨燕族飞得更高更远]]：**
- 雨燕族的负重，很大一部分来自人际关系的烦恼
- 通过课题分离，可以甩掉"社会期待"和"外部评价"的包袱
- 轻装上阵，把精力用在真正重要的事情上

**支撑 [[想要过这样的生活]]：**
- 我不为外部认可而活
- 我不在比较中消耗生命
- 我建立横向关系，而不是纵向关系

## 实践应用

基于这个主张，我在生活中的实践：

**课题分离：**
- LessLive 是否被认可 → 别人的课题
- 我是否把 LessLive 做到我认为对的样子 → 我的课题

**横向关系：**
- 不把用户当成"需要我拯救的人"（纵向）
- 而是"一起探索的伙伴"（横向）

**减少比较：**
- 不追求"比其他产品更好"
- 而是"做最适合雨燕族的"
