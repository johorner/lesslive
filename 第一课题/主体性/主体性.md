## 目标
将自己抽离出来，以便能看到并看清，自己正在成为想要成为的样子

---
## 结构

> [!multi-column] 
>
>> [!info]  [[思考]] ｜**我思故我在**
>> 1️⃣ 对客观世界的主观思考，针对性的批判与辩证分析
>> 2️⃣ 有明确的主题、以及旗帜鲜明的观点、立场和判断
>> 
> 
>> [!info]  [[树洞]] ｜**非理性自我**
>>  1️⃣ 情绪的垃圾桶和避风港，吐槽、宣泄和歇斯底里，真实但非理性
>>  2️⃣ 承接并处理潜意识触发的自我保护，绝对私密，最高级别的隐私
> 
>> [!info]  [[画像]] ｜**认识我自己**
>> 1️⃣ 记录我的人格、性格、风格、偏好等特质，显性表达我是什么样的人
>> 2️⃣ 结合个人意愿，制定优化方案，观察改进效果，保持持续迭代和优化

## 说明
### 能源中心
是第一课题的**能源供应商**，通过自我察觉产出思考成果：
- 树洞承接非理性情绪，可能转化为思考素材
- 思考进行理性加工，产出观点、立场、判断
- 画像沉淀自我认知，形成特质描述和应对策略

**主体性只负责生产能源，不决定能源如何被消费。**
### 内部流转
**树洞 → 思考 → 画像**
- 树洞：非理性情绪的原始状态（困惑、崩溃、突破）
- 思考：理性加工，批判与辩证，形成思考成果
- 画像：关于自我的认知沉淀为特质和策略

### 能源分发
思考成果作为能源，被不同的消费模块按各自职责提炼和使用：
**消费模块：各司其职**
-  [[愿景]] ：提炼为"我想要什么"的具体期望
-  [[使命]] ：提炼为"我愿意付出什么"的明确意愿
-  [[主张]] ：沉淀为完整的理论支撑和信仰体系
-  [[画像]] ：沉淀为自我认知和应对策略
- [[第三课题]]：加工为对外交流的故事素材

**流转规则：**
- 模糊想法可暂存在思考模块或根目录，保持可见
- 明确归属后迁移到消费模块，不保留重复副本
- 消费模块按自己的标准决定如何提炼和沉淀

### 使用原则
- 只记录对客观知识的主观理解和启发，不收集公共知识
- 成果明确用途后应迁移到对应模块，不保留重复副本
- 亲自动手记录，AI 协助完善，但不代劳思考过程
- 内容通常不对外发布，除非被用于服务某个共同体

### 与内驱力的闭环
主体性与内驱力形成健康的闭环，而非循环依赖：
**供应关系：主体性 → 内驱力**
- 主体性产出思考成果（能源）
- 内驱力提炼为愿景、使命、主张（动力）

**指导关系：内驱力 → 主体性**
- 内驱力明确"我想成为什么样的人"（方向）
- 主体性基于此制定改善策略，持续观察"我是否正在成为想要的样子"

**这是螺旋上升的迭代，不是死锁：**
- 新的自我察觉 → 调整内驱力 → 优化改善策略 → 继续观察

> 示例："既然这些东西让你痛不欲生，那反过来看，你真正想要保护的、真正渴望的那个底线，到底是什么？"
