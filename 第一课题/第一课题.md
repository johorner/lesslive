# 与自己相处
把自己作为研究对象，探索和发掘内心深处最真实的自我。
**运行内核：建构稳定而强大的个人内核。**

---
## 目标
- 深度探索并认识自己，辨明真实的个人意志和状态；
- 确立生活中的判断与取舍依据形成稳定个人的内核；
- 不断探索自己的边界，塑造鲜活饱满而丰盈的自我。

---
## 结构

> [!multi-column] 
>
>> [!info]  **构建** [[内驱力]] ｜方向和动力
>> 1️⃣ 挖掘内心深处想要得到的以及愿意付出的
>> 2️⃣ 以旗帜鲜明的立场和观点构建坚实的理论
>> 
> 
>> [!info]  **拥有** [[主体性]] ｜认知和边界
>>  1️⃣ 基于个人意愿而构建的思考目标和领域
>>  2️⃣ 持续跟踪是否正在成为自己想要的样子
> 
>> [!info]  **绽放** [[生命力]] ｜能量和状态
>> 1️⃣ 锦上添花的兴趣爱好让生活变得有趣和多彩
>> 2️⃣ 针对性和系统化的运动项目为健康保驾护航

---
## 说明
- 内驱力是最底层最原始的内核，为几乎所有上层提供最基础的依赖和方向
- 主体性为内驱力提供能源，内驱力为主体性提供方向，形成时序解耦飞轮
- 生命力被定义为生活实现自洽后的奖赏，而非实现自洽的前置任务和条件
